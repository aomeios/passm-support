縱深防禦密碼學架構

Defense-in-Depth Cryptography

多層防御の暗号アーキテクチャ

主密碼（Master Password）全程以可清零字元緩衝區處理，永不寫入磁碟，並經過四道隔離衍生程序保護您的資料庫。

Your Master Password exists only in zeroizable character buffers in RAM and never touches persistent storage.

マスターパスワードはゼロ消去可能なメモリバッファ上でのみ処理され、ストレージには一切保存されません。

鍵導出（ストレッチング）

PBKDF2-HMAC-SHA256 (600,000 iterations, 32B CSPRNG salt) paired with monotonic exponential backoff throttling.

PBKDF2-HMAC-SHA256（60万回反復・32B乱数ソルト）と単調時計ベースの指数バックオフ制限。

Layer 02 · Hardware Binding

職責分離與裝置晶片綁定

Hardware Secret Binding

ハードウェア秘密鍵結合

透過 HKDF-SHA256 分離驗證金鑰與資料庫金鑰，並混入 iOS Keychain / Android Keystore 保護之 32B Device Secret。

HKDF-SHA256 domain separation mixed with a 32-byte Device Secret sealed in iOS Keychain / Android Keystore.

HKDF-SHA256 による鍵分離と、Keychain / Keystore 内の 32B Device Secret との結合。

Layer 03 · Full-DB Cipher

第一層：SQLCipher 全庫加密

Tier 1: SQLCipher AES-256

第1層：SQLCipher 全体暗号化

強制 Raw Key 模式加密整座 SQLite 資料庫與 WAL 日誌，App 退背景到期或鎖屏時自動同步銷毀連線金鑰。

Full database & WAL encryption in raw-key mode; memory keys are zeroized immediately on lock or screen-off.

Raw Key モードによるデータベース全体の AES-256 暗号化。ロック時にメモリ上の鍵を即時消去。

Layer 04 · Bound Field AAD

第二層：欄位級 AAD 認證加密

Tier 2: Per-Field AES-GCM

第2層：フィールド単位 AES-GCM

密碼、CVV/PIN 與安全筆記再以 AES-256-GCM 綁定 34-byte AAD（VaultId + ItemId + ColumnId）防篡改與防跨欄置換。

Sensitive secrets are individually sealed with AES-256-GCM bound to 34-byte AAD (VaultId + ItemId + ColumnId).

パスワードや CVV、メモは 34B AAD（VaultId + ItemId + ColumnId）付き AES-256-GCM で個別封印。
